## Mobile SEO Auditing Capabilities

* **Meta Viewport Inspection**: Verification of `width=device-width, initial-scale=1` and elimination of disorienting viewport scalers.
* **Responsive Grid and Asset Verification**: Detection of non-responsive layouts and media causing horizontal viewport overflow.
* **Touch Target Size and Separation**: Identification of interactive elements failing ergonomic touch standards.
* **Typography and Legibility Checks**: Detection of sub-optimal body copy sizing that degrades mobile user engagement.
* **Mobile-First Indexing Score**: Technical score from 0 to 100 benchmarked against Google Mobile-First Indexing specifications.

## Installation and Execution

Requires Python 3.8 or higher with zero external third-party dependencies.

```bash
git clone https://github.com/TAVARDT-USA/mobile-seo-tester-us.git
cd mobile-seo-tester-us
python mobile_seo_tester.py https://enterprise.com
```

Execute with JSON output formatting:

```bash
python mobile_seo_tester.py https://enterprise.com --json
```
